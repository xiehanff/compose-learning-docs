# 第 83 章：电商首页：分类、轮播与分页商品流

## 1. 本章目标

学完后，你应当能够：

- 写出 `HomeViewModel`：直连 `MallRepo`，一个区块一个状态字段、一个加载方法，各自 try/catch
- 实现下拉刷新、分类筛选、触底加载：`pageNo/hasMore/loadMoreLoading` 三字段 + 请求序号丢弃过期响应
- 用一个 `LazyColumn` 组出「轮播 + 跑马灯 + 分类宫格 + 两列商品流」，图片用 Coil 加载
- 说清 Compose「区块级细粒度刷新」与 GetX `GetBuilder(id)` 的职责对应关系：实际重组范围取决于状态读取位置与能否跳过，不承诺精确到区块

## 2. 接口与区块地图

数据全部来自 ymq mock（第 81 章），DTO 与 `MallRepo` 已在第 82 章就位。首页一个区块对一个接口：

| 区块 | 接口 | MallRepo 方法 |
| --- | --- | --- |
| HomeBanner 轮播 | `POST app-api/shop-product/banner/list` | `loadBannerList()` |
| CategoryGrid 分类宫格 | `GET app-api/merchant/category/getParentCategoryList` | `loadCategoryItems()` |
| MarqueeBar 最近下单 | `GET app-api/shop-trade/order/list-recent-paid` | `loadRecentPaidOrders()` |
| 两列商品流（分页/筛选） | `POST app-api/shop-product/spu/categoryProductList` | `loadRecommendProducts(categoryId, pageNo, pageSize)` |

契约要点：分页壳是 `PageDto{list, total, hasMore}`，翻页只认 `hasMore`；价格字段全是字符串（`"49.90"`），比较前必须数值化；图片 URL 是 302 跳转的真实图，Coil 可直接加载。

## 3. 逐步实现

### 3.1 状态字段与区块加载方法

首页是「四个区块 + 一条分页流」。这里不走第 68 章的 `StateFlow + sealed UiState`（那是状态要跨层共享时的写法）：页面私有的首页状态用一组 `mutableStateOf` 字段更直接——ViewModel 直连 `MallRepo`（第 82 章 3.4），不设 Repository 接口、不做不可变状态聚合、不引入 DI。

<!-- compile decls -->
```kotlin
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewModelScope
import snippets.support.*

// 首页 ViewModel：链路直达 MallRepo，一个区块一个字段 + 一个方法，对齐 GetxController 心智
class HomeViewModel : ViewModel() {
    var banners by mutableStateOf(emptyList<BannerDto>())
        private set
    var categories by mutableStateOf(emptyList<CategoryDto>())
        private set
    var recentPaidOrders by mutableStateOf(emptyList<RecentPaidOrderDto>())
        private set
    var products by mutableStateOf(emptyList<ProductCardDto>())
        private set
    var pageLoading by mutableStateOf(true)   // 整页首屏 loading
        private set
    var pageError by mutableStateOf<String?>(null)   // 整页错误文案
        private set
    var refreshing by mutableStateOf(false)   // 下拉刷新转圈
        private set
    var loadMoreLoading by mutableStateOf(false)   // 触底加载 footer 状态
        private set
    var hasMore by mutableStateOf(true)
        private set
    var selectedCategoryId by mutableStateOf<Long?>(null)
        private set
    private var pageNo = 1
    private var loadSeq = 0   // 请求序号：切分类/刷新后让过期响应作废
    init { loadInitialData() }
    fun loadInitialData() {
        pageLoading = true; pageError = null
        loadBannerList(); loadCategoryItems(); loadRecentPaidOrders(); loadRecommendProducts()
    }
    fun refresh() {
        refreshing = true
        loadInitialData()
    }
    fun selectCategory(categoryId: Long?) {
        if (selectedCategoryId == categoryId) return
        selectedCategoryId = categoryId
        products = emptyList(); pageLoading = true   // 列表清空重查，头部区块保旧数据
        loadRecommendProducts()
    }
    // 头部区块：失败保旧数据，首个错误落到 pageError（已有值不覆盖）
    fun loadBannerList() = viewModelScope.launch {
        try { banners = MallRepo.loadBannerList() } catch (e: Exception) { if (pageError == null) pageError = e.message }
    }
    fun loadCategoryItems() = viewModelScope.launch {
        try { categories = MallRepo.loadCategoryItems() } catch (e: Exception) { if (pageError == null) pageError = e.message }
    }
    fun loadRecentPaidOrders() = viewModelScope.launch {
        try { recentPaidOrders = MallRepo.loadRecentPaidOrders() } catch (e: Exception) { if (pageError == null) pageError = e.message }
    }

    // 商品流第一页：先 ++loadSeq 再请求；回来时对不上号就整段丢弃
    fun loadRecommendProducts() {
        val seq = ++loadSeq; pageNo = 1
        viewModelScope.launch {
            try {
                val page = MallRepo.loadRecommendProducts(selectedCategoryId, pageNo = 1)
                if (seq != loadSeq) return@launch
                products = page.list
                hasMore = page.hasMore
                pageError = null
            } catch (e: Exception) {
                if (seq == loadSeq) pageError = e.message
            } finally {
                if (seq == loadSeq) { pageLoading = false; refreshing = false }
            }
        }
    }

    fun loadMore() {
        if (loadMoreLoading || !hasMore) return
        loadMoreLoading = true
        val seq = loadSeq
        viewModelScope.launch {
            try {
                val page = MallRepo.loadRecommendProducts(selectedCategoryId, pageNo = pageNo + 1)
                if (seq != loadSeq) return@launch
                products = products + page.list
                pageNo += 1
                hasMore = page.hasMore
            } catch (e: Exception) {
                if (seq == loadSeq && pageError == null) pageError = e.message
            } finally {
                if (seq == loadSeq) loadMoreLoading = false
            }
        }
    }
}
```

这与 GetxController 同构：字段直接可变、外部只读（`private set`）、一个区块一个 load 方法。刷新粒度的差别在机制：GetX 要手动 `update([idBanner])` 广播，只有 `GetBuilder(id: ...)` 子树 rebuild；Compose 靠快照系统自动追踪——`HomeBanner(vm.banners)` 只读了 `banners`，字段变化时失效的是读取它的作用域，轮播区块随之重组。这是**职责上的对应**（区块级细粒度刷新），不是机制等价；实际能否跳过更大范围的重组，还取决于子组件参数稳定性与编译器（第 46—47 章）。头部区块失败「保旧数据」是刻意简化：真实工程会给区块单独的错误占位（第 87 章再收敛），这里只让商品流有权决定整页错误，避免一个角标失败掀翻整页。

### 3.2 刷新、切分类与加载更多

- **refresh()** 只置 `refreshing = true` 再复用 `loadInitialData()`。整页转圈只在商品流为空时出现，刷新时旧列表一直保留，转圈由 `loadRecommendProducts` 的 `finally` 收起——`refreshing` 的生命周期交给数据流，不散落在 UI 里。
- **selectCategory()** 先改 `selectedCategoryId`、清空 `products` 再重查第 1 页。清空给用户「切换生效」的即时反馈；等响应回来才变，慢网下像没点上。
- **loadSeq 防旧响应**：连点 101→102 会并发两个第一页请求，先发不一定先回。没有序号，101 的迟到响应会覆盖 102 的列表；`++loadSeq` 后对不上号的响应整段丢弃，`finally` 同样对号才收尾，`pageLoading/refreshing` 不会被旧请求错误地关掉。
- **loadMore()** 的 `loadMoreLoading || !hasMore` 双开关保证幂等：触底会连续触发，缺任何一个都会重复请求同一页。

### 3.3 页面与子组件

子组件全是「数据 + 回调」的哑组件，图片统一用 Coil 的 `AsyncImage`（[官方仓库](https://github.com/coil-kt/coil)，版本为本仓库基线快照）；`viewModel()` 取实例与导航挂页面分别见 [ViewModel 文档](https://developer.android.com/topic/libraries/architecture/viewmodel)与[导航文档](https://developer.android.com/develop/ui/compose/navigation)。价格是字符串：`ProductCard` 里划线价必须 `toBigDecimalOrNull()` 数值化再比较——**适用条件**是服务端保证价格为纯十进制字符串（mock 契约固定两位小数）；格式不保证（千分位、货币符号）时需先清洗。

```kotlin
import androidx.compose.foundation.pager.*
import androidx.lifecycle.ViewModel
import androidx.lifecycle.viewmodel.compose.viewModel
import coil.compose.AsyncImage
import snippets.support.*

// 片段自包含：按第 82 章 BaseResponse 的先例重新声明 3.1 的 HomeViewModel（方法体从略）
class HomeViewModel : ViewModel() {
    var banners by mutableStateOf(emptyList<BannerDto>())
    var categories by mutableStateOf(emptyList<CategoryDto>())
    var recentPaidOrders by mutableStateOf(emptyList<RecentPaidOrderDto>())
    var products by mutableStateOf(emptyList<ProductCardDto>())
    var pageLoading by mutableStateOf(true)
    var pageError by mutableStateOf<String?>(null)
    var refreshing by mutableStateOf(false)
    var loadMoreLoading by mutableStateOf(false)
    var hasMore by mutableStateOf(true)
    var selectedCategoryId by mutableStateOf<Long?>(null)
    fun loadInitialData() {}
    fun refresh() {}
    fun selectCategory(categoryId: Long?) {}
    fun loadMore() {}
}

// 轮播：页数由 rememberPagerState 的 lambda 返回，HorizontalPager 负责横滑
@Composable
fun HomeBanner(banners: List<BannerDto>, modifier: Modifier = Modifier) {
    if (banners.isEmpty()) return
    HorizontalPager(state = rememberPagerState { banners.size }, modifier = modifier) { page ->
        AsyncImage(
            model = banners[page].imgUrl, contentDescription = banners[page].title,
            contentScale = ContentScale.Crop, modifier = Modifier.fillMaxWidth().aspectRatio(2.6f),
        )
    }
}
// 跑马灯：每 2.5 秒轮换一条「最近下单」；orders 变化时定时器自动重启
@Composable
fun MarqueeBar(orders: List<RecentPaidOrderDto>) {
    if (orders.isEmpty()) return
    var index by remember { mutableStateOf(0) }
    LaunchedEffect(orders) {
        while (true) {
            delay(2500)
            index = (index + 1) % orders.size
        }
    }
    Text(orders[index].displayText, maxLines = 1, overflow = TextOverflow.Ellipsis,
        color = MaterialTheme.colorScheme.onSurfaceVariant, style = MaterialTheme.typography.labelMedium)
}
// 分类宫格：FlowRow 自动换行；点中的分类再点一次取消筛选（onSelect 回传 null）
@Composable
fun CategoryGrid(categories: List<CategoryDto>, selectedCategoryId: Long?, onSelect: (Long?) -> Unit) {
    FlowRow(
        modifier = Modifier.fillMaxWidth().padding(vertical = 4.dp),
        horizontalArrangement = Arrangement.spacedBy(4.dp, Alignment.CenterHorizontally),
    ) {
        categories.forEach { c ->
            val selected = c.id == selectedCategoryId
            Column(
                horizontalAlignment = Alignment.CenterHorizontally,
                modifier = Modifier.clip(RoundedCornerShape(8.dp))
                    .clickable { onSelect(if (selected) null else c.id) }
                    .padding(horizontal = 10.dp, vertical = 6.dp),
            ) {
                AsyncImage(model = c.iconUrl, contentDescription = c.name, modifier = Modifier.size(44.dp))
                Text(c.name, style = MaterialTheme.typography.labelMedium,
                    color = if (selected) MaterialTheme.colorScheme.primary else MaterialTheme.colorScheme.onSurface)
            }
        }
    }
}
// 商品卡：划线价先 toBigDecimalOrNull 数值比较，字符串不能直接比大小
@Composable
fun ProductCard(product: ProductCardDto, onClick: () -> Unit, modifier: Modifier = Modifier) {
    Card(onClick = onClick, modifier = modifier) {
        AsyncImage(
            model = product.mainImgUrl, contentDescription = product.name,
            contentScale = ContentScale.Crop, modifier = Modifier.fillMaxWidth().aspectRatio(1f),
        )
        Column(Modifier.padding(8.dp)) {
            Text(product.name, maxLines = 2, overflow = TextOverflow.Ellipsis, style = MaterialTheme.typography.bodySmall)
            Row(verticalAlignment = Alignment.CenterVertically) {
                Text("¥${product.price}", color = MaterialTheme.colorScheme.error, style = MaterialTheme.typography.titleSmall)
                val origin = product.originPrice.toBigDecimalOrNull()
                val price = product.price.toBigDecimalOrNull()
                if (origin != null && price != null && origin > price) {
                    Text("¥${product.originPrice}", color = MaterialTheme.colorScheme.outline,
                        style = MaterialTheme.typography.labelSmall, textDecoration = TextDecoration.LineThrough)
                }
            }
        }
    }
}

// 首页组装：整页一个 LazyColumn；loading/错误只在商品流为空时整页接管
// PullToRefreshBox 在 material3 的子包里，通配 import 覆盖不到，需显式引入
import androidx.compose.material3.pulltorefresh.PullToRefreshBox

@Composable
fun HomeScreen(vm: HomeViewModel, onOpenProduct: (Long) -> Unit, onOpenCart: () -> Unit) {
    when {
        vm.pageLoading && vm.products.isEmpty() ->
            Box(Modifier.fillMaxSize(), contentAlignment = Alignment.Center) { CircularProgressIndicator() }
        vm.pageError != null && vm.products.isEmpty() -> Column(
            Modifier.fillMaxSize().padding(24.dp), verticalArrangement = Arrangement.Center,
            horizontalAlignment = Alignment.CenterHorizontally,
        ) {
            Text(vm.pageError ?: "加载失败", color = MaterialTheme.colorScheme.error)
            Spacer(Modifier.height(8.dp))
            Button(onClick = vm::loadInitialData) { Text("重试") }
        }
        else -> PullToRefreshBox(isRefreshing = vm.refreshing, onRefresh = vm::refresh, modifier = Modifier.fillMaxSize()) {
            val listState = rememberLazyListState()
            // 触底判定：最后一个可见索引进入「总数 - 4」缓冲区即认为接近底部
            val nearEnd by remember {
                derivedStateOf {
                    (listState.layoutInfo.visibleItemsInfo.lastOrNull()?.index ?: 0) >= listState.layoutInfo.totalItemsCount - 4
                }
            }
            // 键里带 products.size/hasMore/loadMoreLoading：nearEnd 常真时，状态一变还能再次触发
            LaunchedEffect(nearEnd, vm.products.size, vm.hasMore, vm.loadMoreLoading) {
                if (nearEnd) vm.loadMore()
            }
            LazyColumn(state = listState, modifier = Modifier.fillMaxSize()) {
                item(key = "banner") { HomeBanner(vm.banners, Modifier.padding(horizontal = 12.dp, vertical = 8.dp)) }
                item(key = "marquee") { MarqueeBar(vm.recentPaidOrders) }
                item(key = "category") { CategoryGrid(vm.categories, vm.selectedCategoryId, onSelect = vm::selectCategory) }
                item(key = "cart") { IconButton(onClick = onOpenCart) { Icon(Icons.Filled.ShoppingCart, contentDescription = "购物车") } }
                items(vm.products.chunked(2), key = { it.first().id }) { row ->
                    Row(
                        modifier = Modifier.fillMaxWidth().padding(horizontal = 8.dp),
                        horizontalArrangement = Arrangement.spacedBy(8.dp),
                    ) {
                        row.forEach { p ->
                            ProductCard(p, onClick = { onOpenProduct(p.id) }, modifier = Modifier.weight(1f).padding(vertical = 4.dp))
                        }
                        if (row.size == 1) Spacer(Modifier.weight(1f))
                    }
                }
                if (vm.hasMore) item(key = "footer") {
                    Box(Modifier.fillMaxWidth().padding(12.dp), contentAlignment = Alignment.Center) {
                        CircularProgressIndicator(Modifier.size(22.dp))
                    }
                }
            }
        }
    }
}

// 用法包装：viewModel() 从最近的 ViewModelStoreOwner 取实例，导航目的地处只需要 MallHomeEntry
@Composable
fun MallHomeEntry(onOpenProduct: (Long) -> Unit, onOpenCart: () -> Unit) {
    val vm: HomeViewModel = viewModel()
    HomeScreen(vm, onOpenProduct, onOpenCart)
}
```

### 3.4 下拉刷新与触底加载

- **`PullToRefreshBox` 必须占满尺寸**（`fillMaxSize`）：它自身是个 Box，不给尺寸手势区域就塌陷。它是 material3 的实验 API，版本行为以 [material3 releases](https://developer.android.com/jetpack/androidx/releases/material3) 为准，本仓库基线快照内可用。
- **触底判定用 `derivedStateOf`**：读的是 `LazyListLayoutInfo`，不触碰组合期状态；「总数 - 4」留缓冲区，行高不一时也稳。
- **`LaunchedEffect` 的键是最容易踩的坑**：只写 `LaunchedEffect(shouldLoadMore)` 时，滑到底后 Boolean 常真、键不再变化，加载完第二页也不会再触发，分页卡死。键里加 `products.size/hasMore/loadMoreLoading`，任一变化都会重启副作用再次判定。
- footer 是 `if (vm.hasMore)` 下的 item：`hasMore=false` 后直接从列表消失，不留空转圈。

## 4. 实际执行过程

1. mock 推荐商品共 14 条、`pageSize=10` 恰好两页：首屏 10 条 + `hasMore=true`；滑到第 7 个左右（缓冲 4）footer 转圈、追加 4 条；`hasMore=false` 后 footer 消失，再滑也不发请求。下拉刷新时旧内容保留，收起后四区块数据更新。

3. 停掉 mock（或断开 `adb reverse`）造错误态：整页错误 + 重试按钮；重启 mock 后点重试恢复。
4. 数据改乱随时 `curl http://localhost:3001/__reset` 还原再验。

## 5. Flutter/ymq 对照

对照 ymq 的 `MallHomeController`（GetX）：

- **细粒度刷新**：它为每个区块定义 `idCategory/idHot/idRecommend/idBanner/idNotice/idPageLoading` 等 update id，`loadBannerList()` 成功后 `update([idBanner])`，只有对应 `GetBuilder(id: ...)` 子树 rebuild。我们的对应物是一个区块一个 `mutableStateOf` 字段——`HomeBanner(vm.banners)` 只依赖 `banners`。职责对应，机制不同（手动广播 vs 快照自动追踪）。
- **头部并发刷新**：它的 `refreshHeaderData()` 用 `Future.wait([loadBannerList(), ...])` 等头部请求全部回来；我们 `loadInitialData()` 里四个方法各自 `launch` 天然并发，收尾统一交给商品流的 `finally`。
- **分页**：它把 `pageNo/hasMore/累加` 装进 `YQListPaginationManager(fetch:, pageSize: 10)`，对外只剩 `recommendPager.refresh()` 和 loadMore 后 `update([idRecommend])`。我们的三字段 + `loadSeq` 就是这个管理器的手写展开——拆开轮子看一次，才知道它替你挡了什么。
- 它的 `loadMoreRecommendProducts` 用 `_loadMoreIgnoringHasMore` 忽略 `hasMore` 以重试失败页；我们用「失败不置 `hasMore=false`，footer 停转后可再滑重试」达到同效。

## 6. 常见错误

- **LazyColumn 里嵌同向滚动容器**：商品流区套 `LazyVerticalGrid` 或 `verticalScroll` 的 Column，同向无限高约束直接抛异常。两列用 `chunked(2)` 切行。
- **`items` 不给 key**：追加第二页后列表项失去稳定身份，与条目关联的状态（动画、滚动定位）可能错位，图片组件也可能因条目被复用而重新加载。行 key 用 `it.first().id`，footer 用字符串 key 区分；key 的作用是稳定身份，不承诺零重组（第 17 章）。
- **价格字符串直接比较**：`"9.90" > "49.90"` 按字典序成立，划线价会乱显示；必须 `toBigDecimalOrNull()` 数值化。
- **触底键只用 Boolean**：`LaunchedEffect(shouldLoadMore)` 条件常真后不再重启，分页卡死；键要含 `products.size/hasMore/loadMoreLoading`。
- **切分类不防旧响应**：101 的迟到响应覆盖 102 的列表，UI 与选中分类不符；请求序号必须发前自增、回后校验。
- **`PullToRefreshBox` 不占满尺寸**：忘了 `fillMaxSize`，下拉手势区塌陷、内容错位。
